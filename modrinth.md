A Ribbits addon for Minecraft 1.21.1. Install either the NeoForge set or the Fabric set.

## NeoForge

Required: `reallyusefulribbits-neoforge-1.21.1-1.0.0.jar`, Kotlin for Forge 5.8.0, Ribbits `1.21.1-NeoForge-4.1.6`, GeckoLib 4.7.6, and YUNG's API `1.21.1-NeoForge-5.1.5`. Optional: Patchouli `1.21.1-93-neoforge` for the guidebook, Farmer's Delight, and Wandering Ribbit.

## Fabric

Required: `reallyusefulribbits-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1`, Fabric Language Kotlin `1.13.2+kotlin.2.1.20`, Ribbits `1.21.1-Fabric-4.1.6`, GeckoLib 4.7.6, YUNG's API `1.21.1-Fabric-5.1.5`, and Cloth Config `15.0.140` (Ribbits requires it). Optional: Patchouli `1.21.1-93-fabric` for the guidebook (Fiber is already inside that jar; do not install it separately), Farmer's Delight, and Wandering Ribbit. No config screen: `config/reallyusefulribbits-server.properties`.
