# Really Useful Ribbits

**[English](README.md)** · **[Русский](README.ru.md)**

Аддон для **Minecraft 1.21.1** к моду [Ribbits](https://modrinth.com/mod/ribbits), на NeoForge и на Fabric. Маракасом можно задать риббиту точку дома, а рыбаки, фермеры, торговцы, чародеи и nitwit начинают делать что-то полезное. Написан на Kotlin. Ставится набор одного загрузчика, не оба сразу.

Интерфейс и внутриигровая книга есть на русском и английском (язык берётся из настроек клиента).

## Загрузки

Готовые jar лежат в [GitHub Releases](https://github.com/Nergan/really-useful-ribbits-mod/releases/latest). Пуш в `main` обновляет страницу GitHub Release для каждой пары версии Minecraft и загрузчика. На странице есть `all-jars.zip`.

Скачайте один набор и положите эти файлы в папку `mods`.

## Возможности

- **Новый дом.** ПКМ **маракасом** из оригинального Ribbits по риббиту ставит точку дома там, где он стоит. Старая ферма, рыбацкая вода и сундук забываются, и фермер или рыбак больше не возвращается в деревню. Маракас продаёт торговец-риббит. За это выдаётся достижение «значит теперь это мой новый дом…». Сажать риббита на голову больше нельзя.
- **Общая территория.** Каждый рабочий риббит смотрит настраиваемый радиус (по умолчанию 64 блока). Несколько риббитов могут работать на одной площади. Зарезервированный блок культуры или воды другой риббит не перехватывает.
- **Рыбак.** Биндится на один блок воды и один контейнер. Садится на берег с анимацией удочки, рыбачит как игрок (всплески к поплавку, затем улов) и носит до 4 предметов. Полублок в верхней части блока воды он не считает местом рыбалки. Набрав 4, встаёт, подходит к контейнеру и кладёт улов обычными стопками, затем возвращается к воде. ПКМ подсвечивает риббита, воду и контейнер. Если бинда нет — кваканье боли и angry_villager.
- **Фермер.** Биндится на одну связную ферму (пашня, пашня Farmer's Delight, песок душ, нижние блоки тростника, культуры в воде или на грязи и кустовые культуры вроде помидоров и винограда) и один контейнер. Сладкие ягоды и другие колючие кусты не трогает. Собирает, сеет, вспахивает, поливает пашню и иногда помогает светоягодам появиться на лозах. Арбузы, тыквы, тростник и адский нарост тоже в работе. К сундуку подходит сам, издалека ничего не кладёт и не достаёт. Инвентарь 4×64. ПКМ сыпет частицы по ферме и контейнеру.
- **Торговец.** 27 слотов по 256. Сначала случайные товары плюс 256 изумрудов и 256 аметистов. Ищет жителей, странствующих торговцев, странствующих риббитов и любых других торговцев, копирует покупаемый предмет (сделки на максимуме, без лимита склада), собирает до 16 сделок за аметисты без повторов типа предмета и квакает на игрока, пока тот не поторгуется или не проигнорирует. Всегда ходит со скоростью ×1.5.
- **Чародей.** ПКМ осколком аметиста бросает одно из 35 заклинаний, см. [Заклинания чародея](#заклинания-чародея). Проклятия переживают смерть. Зачарованное золотое яблоко, отданное чародею, снимает их все и останавливает порчу мира; обычные эффекты по-прежнему снимает молоко. Эндермены в радиусе убегают. В остальном бродит как обычный риббит.
- **Nitwit.** Накладывает удачу в радиусе. Подбирает лут с земли (27 слотов по 64) и иногда относит его игроку, выбрасывая как по Q.
- **Книга (необязательно).** Если установлен [Patchouli](https://modrinth.com/mod/patchouli), при первом заходе в мир выдаётся «Очень полезные риббиты». Крафт: обычная книга и гигантская кувшинка. Книга также лежит во вкладке мода Ribbits. Без Patchouli остальной аддон работает как обычно. Сами профессии даёт Ribbits; этот аддон только даёт этим лягушкам работу.

## Заклинания чародея

У каждого заклинания есть баллы в серверных настройках. Шанс заклинания — его баллы, делённые на сумму баллов всех заклинаний; 0 выключает заклинание. По умолчанию баллы в сумме дают 10000, поэтому 100 баллов — это 1%. Чародей бросает только то, что сейчас может случиться: без зачаровываемого предмета нет зачарования, второго гигантского вардена при живом первом не будет и так далее.

**Уровень хаоса по умолчанию: 0.** Хаос выравнивает шансы: вес заклинания — его баллы в степени `1 - хаос/100`. При 0 шансы ровно как в таблице, при 100 все включённые заклинания равновероятны. Редкие на любом уровне остаются реже частых.

Проклятия переживают смерть: эффекты, вверх ногами, размер, запас здоровья, превращение, ник, шейдер, перевёрнутое управление, VVVVVV, огненные шары и молнии из руки и полёт. Обычные эффекты по-прежнему снимает молоко. Всё остальное снимает только зачарованное золотое яблоко, отданное чародею.

## Установка

1. Установите NeoForge 21.1.x или Fabric Loader для 1.21.1.
2. Скачайте подходящий набор из [последнего Release](https://github.com/Nergan/really-useful-ribbits-mod/releases/latest).
3. Положите этот набор в `mods`. NeoForge-jar в Fabric-сборку не класть, и наоборот.
4. По желанию добавьте Patchouli того же загрузчика.

Аддон нужен и на клиенте, и на сервере. Зависимости можно взять и с [Modrinth](https://modrinth.com/mod/ribbits), не из GitHub Release.

## Настройки

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `scan_radius` | `64` | Как далеко риббит ищет воду, ферму, контейнер, удачу, эндерменов и рост растений чародея |
| `chaos_level` | `0` | Насколько ровными становятся шансы чародея: 0 оставляет баллы как есть, 100 уравнивает все включённые заклинания |
| баллы заклинаний | см. [Заклинания чародея](#заклинания-чародея) | Один ключ на заклинание, от 0 до 1000000. 0 выключает заклинание |

### NeoForge

В игре: Mods → Really Useful Ribbits → Config.

Файл: `config/reallyusefulribbits-server.toml` в каталоге игры или сервера. Копия в `<мир>/serverconfig/` переопределяет его для одного мира. Баллы заклинаний — раздел `[sorcerer.spells]`, один ключ на заклинание. В файле старой версии, где этого раздела нет, `chaos_level = 25` был старым значением по умолчанию и становится 0.

Конфиг типа `SERVER`: значения задаёт сервер и рассылает игрокам. В онлайне имеет значение только то, что стоит на сервере.

### Fabric

Экрана настроек нет. Сервер читает `config/reallyusefulribbits-server.properties` при запуске. Ключи: `scan_radius` (по умолчанию 64), `chaos_level` (по умолчанию 0) и по одному `spell.<ключ>` на заклинание, например `spell.ender_dragon=93`. Файл старой версии, где ключей заклинаний нет, переписывается со всеми ключами; его `chaos_level=25` был старым значением по умолчанию и становится 0. На выделенном сервере файл лежит в каталоге сервера. После правки нужен перезапуск. Это один файл на весь инстанс, не отдельный конфиг мира.
